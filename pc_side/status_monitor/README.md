# B-U585I-IOT02A ステータスモニタ

テレメトリファームウェア（ボードが常時送信）を受信して、ボタン・各種センサー・
オーディオ・電波状況・メモリ使用状況を表示する簡易UIアプリ。

## 起動

```bash
pip install -r requirements.txt
python app.py
```

## タブ構成

| タブ | 内容 |
|---|---|
| ダッシュボード | ボタン/環境センサー(温湿度・気圧・照度・ToF)/モーション/音声レベル/電波/メモリのパネル表示 |
| 全データ | 全項目（センサー値・内部データ・受信統計）を一覧テーブルで表示 |
| オーディオ | 16kHz実音声のリアルタイム波形表示、WAV録音(recordings/へ保存)、再生 |

## 接続方式と手順

### UART（推奨・全機能対応）
1. ボードのST-LINK側USB（CN8）をPCに接続
2. 接続方式=UART、COMポート（例 COM9）を選び「接続」
3. 921600baudで133Bフレームを10Hz受信。オーディオストリーミングもこの接続のみ対応

### Bluetooth (BLE)
1. PCにBluetoothアダプタがあること（Windows設定でBluetooth ON）
2. ボード起動時にファームがSTM32WB5MMGモジュールのP2Pサーバー＋アドバタイズを自動起動
3. 接続方式=BLE、デバイス名に「P2PSRV1」（見つからない場合は部分名やMACアドレスでも可）→「接続」
4. アプリがスキャン→接続→通知購読し、コンパクト版ステータス（ボタン/温湿度/気圧/照度/ToF/音声レベル）を1Hzで受信
- 注意: BLEはコンパクト版のみ（波形・メモリ詳細・モーションはUARTで参照）

### Wi-Fi (TCP)
- ボード側のWi-Fi TCPサーバーは**未実装**（EMW3080のTCP/IPスタック未導入のため将来対応）
- 現状は「同じフレームストリームをTCPで中継する」用途向け: 例えば `ser2net` や
  `socat` でCOMポートをTCP公開したPCに、別のPCから host:port 指定で接続できる

## オーディオ機能

1. UARTで接続
2. オーディオタブ →「ストリーミング開始」（ボードへ 'a' を送信、16kHz/16bit/モノラルPCMがCMD 0x03フレームで届く）
3. 「録音開始」→「録音停止」で `recordings/rec_*.wav` に保存
4. 「再生」で最後の録音をPCのスピーカーで再生
- 実測: 5.12秒で81,920サンプル欠損ゼロ・CRCエラー0

## プロトコル

- フレーム形式は要件定義書11.2節（SOF 0xAA / CRC-16 CCITT-FALSE / EOF 0x55）
- CMD 0x01=フルステータス(133B), 0x02=コンパクト(BLE), 0x03=音声PCM(512サンプル)
- ファームのprintfログはパーサが分離して「ファームウェアログ」欄に表示
- ボードへのコンソールキー: 't'=ハードテスト16項目実行, 'a'/'s'=音声ストリームON/OFF
